AD STYLES - PRODUCT PHOTOS
=========================

Every product photograph is a real photo file in this img/ folder.
To change a photo: save the new file here with a new name, then change the file name
in the product list near the top of the page code (search for "STORE DATA").
Keep the same shape (portrait for clothes, square for shoes) so cards stay neat.

Cut-out garments (shirt-*, pants-*, jeans-*, rack-tee-*, shoe-derby, shoe-white-leather,
tee-teddy-folded) are transparent WebP files shown on the studio background.
The hanger showrooms use shirt-*.webp and rack-tee-*.webp.
